Robotnik - Experiments with Robotics Simulation
===============================================
A knowledge-based web application for robotic access and retrieval using IBM Watson. Provides an interface for textual communication with a Webots simulation of two robots collaboratively operating a virtual warehouse. Users can query the warehouse's contents using the app and submit items for deposit/retrieval.
